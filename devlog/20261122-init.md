# esimv1-viewer: where this repository came from

22 November 2026. This repository was cut out of `anselm/esimv1` by Claude (Fable 5.2, the
esimv1 room on canada1, session https://claude.ai/code/session_018TGCFiQHbUYn12HkNti2xk)
on Anselm's word, as part of splitting esimv1 into a hub, an engine, a viewer and a
repository for each scenario with a life of its own.

Anselm, that day:

> esimv1 repo naming - yes i just felt it was easier to leave esimv1 as the user facing
> repo - true the naming is not perfect, but it feels like we break less stuff if esimv1
> acts as the hub. esimv1-core sounds good. esimv1-viewer sounds good. repos only for
> truly significant scenarios makes sense esimv1-pallisades, esimv1-portland,
> esimv1-earth2100, esimv1-playable-sausalito and leave rest. we will move githubs later -
> can stay in /anselm .

and, to the question of going ahead: "yes push new repos."

The history here is the history of these files in esimv1, kept by `git filter-repo`; the
commit messages are the originals and speak of the whole of esimv1 as it was. The thinking
behind the split, the order it was done in and what was checked at each step are in
esimv1's devlog: `devlog/20261122-a-refactor-pass-how-to-approach.md`, and before it
`devlog/20261122-playable-sausalito-as-an-exercise.md`. Everything written about these
files before this day is in esimv1's `devlog/` and is not copied here.
